# 🚩 CTF Write-ups

A personal collection of Capture The Flag write-ups, solve scripts, notes, and challenge files.

This repository documents my approach to solving different CTF challenges, including the reasoning process, useful tools, exploitation steps, and final solutions. The goal is to keep each write-up clear enough to review later and useful for anyone learning similar techniques.

## 📁 Repository Structure

Each folder usually represents a CTF event or challenge category. A typical challenge folder looks like this:

```text
CTF Event/
└── [Category] Challenge Name/
    ├── README.md        # Write-up and solution explanation
    ├── solve.py         # Solve script, if needed
    ├── files/           # Provided challenge files
    └── img/             # Screenshots or proof images
```

## 📝 Write-up Style

Most write-ups follow this format:

1. Challenge summary
2. Initial analysis
3. Vulnerability or key idea
4. Exploitation / solving steps
5. Final flag or result

## ⚠️ Note

These write-ups are for learning and documentation purposes. Challenge files and solutions are shared to explain techniques used in legal CTF environments.
